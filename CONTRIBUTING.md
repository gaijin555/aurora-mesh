# Как участвовать

## Что приветствуется

- Критика архитектуры и поиск слабых мест.
- Юридические замечания по конкретным юрисдикциям.
- Ссылки на существующие исследования (FSO, VANET, LoRa voice, DePIN).
- Симуляции покрытия.
- Формальные спецификации протоколов.

## Что не приветствуется

- Призывы к нарушению закона.
- Инвестиционные советы и обещания прибыли.
- Политические лозунги без технической конкретики.
- Спам и самореклама.

## Процесс

1. Обсуждение → [Discussions](../../discussions).
2. Issue по шаблону.
3. Pull request с описанием изменений и ссылками на источники.

## Стиль

- Markdown.
- Один язык на файл (русский или английский).
- Технические термины — по возможности с расшифровкой.
